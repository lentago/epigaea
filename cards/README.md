# cards/ has moved

Instruction cards now live in [`signage/cards/`](../signage/cards/), alongside
the other signage types. The contract, how to make a piece, and the index are
in [`signage/README.md`](../signage/README.md). Cards publish to
`http://pub.lan/signage/cards/<slug>/`, and the old `http://pub.lan/cards/<slug>/`
addresses redirect there.
